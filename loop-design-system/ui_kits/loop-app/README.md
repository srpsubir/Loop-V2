# Loop — Mac app UI kit

An interactive, high-fidelity recreation of the Loop desktop app, composed from
the design-system components (`window.LoopDesignSystem_96f8bb`). Open
`index.html`.

## Screens & flow
- **Home** (`HomeScreen.jsx`) — a serif greeting, your **chapters** as photo-cover
  cards (with stacked crew avatars), and an **"On your mind"** strip of people you
  haven't spoken to in a while, each with a gentle "Say hi".
- **Chapter** (`ChapterScreen.jsx`) — a warm cover banner with the chapter title
  in Lora, a one-line italic blurb, a People / Moments segmented toggle, and the
  **crews** within, each a paper card of `PersonRow`s.
- **Person** (`PersonScreen.jsx`) — a large portrait, serif name, chapter tags,
  "Reach out" / "Add a moment", and **"Your story together"** — a memory timeline
  mixing notes, photos, and milestones.

Navigation is click-through: chapter card → Chapter, person row → Person, back
arrows and the Loop wordmark return home. The top-bar **search** opens a live
popover of everyone, filtered as you type.

## Composition
- `App.jsx` — window chrome (traffic lights in the toolbar), top bar, search
  popover, and route state. No sidebar nav — by design.
- `data.jsx` — fictional people, chapters, crews, and a memory timeline.
- `ui.jsx` — shared helpers: `Ic` (Lucide icon) and `Photo` (warm-duotone image).

## Notes
- People use the initials `Avatar` fallback (warm, name-tinted) — no portrait
  photos are bundled. Chapter covers and memory photos are warm-tinted
  placeholders (see root README's asset note).
- Built against `_ds_bundle.js`; if components don't render, the bundle is
  regenerated by the compiler on each turn.
