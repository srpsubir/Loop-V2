The signature Loop unit — a person as a line in a photo album. Composes Avatar.

```jsx
<PersonRow
  name="Priya Raman"
  src={photo}
  note="Last spoke 3 weeks ago · Edinburgh"
  ring="sage"
  trailing={<IconButton icon={<MessageIcon/>} label="Note" />}
/>
```

Props: `name` (serif), `src`, `meta`/`note` (note wins), `ring`, `trailing`, `onClick`. Hovers to a soft surface wash.
